# ADS Animační Systém v2 — Zbývající Úkoly

## ✅ HOTOVO
- **Crossfading** — Plynulé přechody s lerp/slerp blendingem
- **Animation Notifies** — ADM v4 parser, Lua `onAnimNotify` event
- **Lua API** — `World.PlayBlendSpace()` a event handlers
- **Blender Export** — Notifies z pose markers do ADM
- **Test Resources** — blend_space_test, ik_test, root_motion_test créées

---

## ⏳ ZBÝVÁ

### 1. Blend Spaces — Runtime Evaluace
**Co:** Implementovat `evaluate_blend_space_weights()` systém
- **Algoritmus:** Inverse Distance Weighting (IDW) pro 2D prostor
- **Výstup:** `active_clips: Vec<(String, f32)>` s jmény klipů a vypočítanými vahami
- **Integrace:** `apply_adm_animations` musí umět blendovat více klipů najednou
- **Soubory:** `core_drawable/src/adm.rs`, nový systém v `PostUpdate`

**Test:** `resources/example/blend_space_test/` je připraven, měl by pokazovat plynulé blendování mezi klippy dle move vektoru

**ADM Format:** v5 parser pro blend space definice z Blenderu (zatím stub `Vec::new()`)

---

### 2. Runtime IK — Two-Bone Solver
**Co:** Procedurální úpravy kostí pomocí IK řetězů
- **Komponenty:** `IkTarget`, `IkChain { root_bone, tip_bone, target_pos }`
- **Solver:** Two-Bone IK (FABRIK nebo CCD)
- **Foot IK:** Raycast z kyčlí dolů → umístit chodidla na terén
- **Weapon IK:** Připjout levou ruku na zbraňový socket
- **Soubory:** Nový modul `core_drawable/src/ik.rs`, Lua API `World.AddIkChain()`

**Test:** `resources/example/ik_test/` sleduje výšky, jakmile bude solver aktivní

---

### 3. Root Motion — Extrakce a Aplikace
**Co:** Oddělení pohybu kořenové kosti od ostatních animací
- **Extrakce:** `RootMotionExtractor` sleduje `DEF_Root` deltu mezi framy
- **Aplikace:** Delta se aplikuje jako `Transform` změna (respektuje autoritativitu serveru)
- **Parametr:** Toggle v Lua API a Blender exportu (`enable_root_motion`)
- **Soubory:** Integrace do `core_drawable/src/adm.rs` a `host_client/src/gameplay.rs`

**Test:** `resources/example/root_motion_test/` monitoruje pohyb entity, měl by odpovídat animaci

---

## 4. Performance & LOD Pravidla
- IK a Blend Space výpočty musí respektovat Skeletal Pruning (LOD2+ se nespouští)
- Paralelizace: Query-based bez side-efektů, Query iterace pro desítky entit
